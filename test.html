1. 西里爾字母（偽造英文同形字）測試

正常英文： paypal.com / apple.com / twitter.com

混用西里爾字母： pаypаl.com / аррlе.com / twittеr.com

2. 特殊數學符號 / 花體字 (Math Unicode) 測試

花體字： 𝒫𝑜𝓁𝓎𝓂𝒶𝓇𝓀𝑒𝓉 / 𝒫𝒶𝓎𝒫𝒶𝓁

粗體數學字： 𝗛𝗲𝗹𝗹𝗼 𝗪𝗼𝗿𝗹𝗱

雙線體： ℙ𝕠𝕝𝕪𝕞𝕒𝔯𝕜𝕖𝔱

3. 非 ASCII 字元（全形字與特殊標點）測試

全形英文與數字： ａｂｃ１２３

全形標點符號： Hello World！ 這是一段測試文字？

4. 文字超連結 <a> 測試

正常連結： https://apple.com

偽造連結： https://аррlе.com（點擊測試，功能不受影響）

5. 圖片超連結 <a><img /></a> 測試

點擊進入 PayPal（含異字元標題：pаypаl.com）
